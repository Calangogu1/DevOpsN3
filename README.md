DevOps N3

Descrição

Aplicação desenvolvida em Node.js com Express para a disciplina de DevOps.

Tecnologias

* Node.js
* Express
* Jest
* Selenium
* GitHub Actions
* Docker

Como executar

Instale as dependências:

npm install

Inicie a aplicação:

npm start

Acesse:

http://localhost:3000

Testes

Rodar testes unitários:

npm test

Rodar cobertura:

npm run coverage

Teste Selenium

node selenium/seleniumTest.js

CI

A integração contínua é executada automaticamente pelo GitHub Actions. DevOps N3
